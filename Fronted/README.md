# Syshub - Frontend (Vue 3 + Vite)

Proyecto Vue 3 usando Composition API y Vite.

Requisitos:
- Node.js 18+ y npm (o yarn)

Instalación y ejecución:

```bash
cd "Fronted"
npm install
npm run dev
```

Scripts (en `package.json`):
- `dev` - arranca el servidor de desarrollo (Vite)
- `build` - construye para producción
- `preview` - sirve la carpeta `dist` para previsualizar la build

Notas:
- El punto de entrada es `src/main.js`.
- Componentes de ejemplo usan la Composition API (`<script setup>`).
