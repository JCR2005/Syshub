## Descripción del Proyecto

SYSHUB es una propuesta conceptual de plataforma digital orientada a preservar, organizar y difundir el conocimiento académico generado por estudiantes de Ingeniería en Ciencias y Sistemas.

El sistema busca mitigar la pérdida de información académica que ocurre al finalizar cada semestre, permitiendo que proyectos, tareas, soluciones técnicas y discusiones permanezcan accesibles para futuras generaciones de estudiantes.

El enfoque del proyecto se basa en una visión sistémica donde la interacción entre usuarios permite la generación de conocimiento como una propiedad emergente dentro del ecosistema académico.

---

## Objetivo del Proyecto

Diseñar conceptualmente un sistema que permita:

- Centralizar proyectos y tareas académicas
- Facilitar la discusión técnica entre estudiantes
- Organizar conocimiento por cursos y áreas tecnológicas
- Permitir la curaduría de contenido académico por auxiliares

## Alcance del Proyecto

Este repositorio contiene la documentación correspondiente a la **Fase 1 del proyecto**, la cual se enfoca en:

- Análisis del sistema
- Definición del alcance
- Modelado sistémico
- Diseño conceptual de la base de datos
- Diseño de procesos
- Bocetos de interfaz

En esta fase **no se desarrolla código ni software funcional**, ya que el objetivo es la planificación y el diseño del sistema.

## Módulos Principales del Sistema

El diseño conceptual de SYSHUB contempla cuatro módulos principales:

1. Gestión de Identidad y Perfiles  
2. Repositorio de Proyectos y Tareas  
3. Foros y Sección Social (Sys-Reddit)  
4. Panel de Administración y Moderación  

---

## Tecnologías Consideradas (Conceptuales)

Aunque esta fase no incluye desarrollo, el sistema podría implementarse en el futuro utilizando tecnologías como:

- Backend: Java / Node.js / Python
- Base de datos: PostgreSQL o MySQL
- Frontend: HTML, CSS, JavaScript
- Control de versiones: Git y GitHub
